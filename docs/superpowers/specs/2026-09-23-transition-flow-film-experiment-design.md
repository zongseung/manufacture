# 전이흐름 조건부 FiLM 실험 설계

## 목적과 범위

연구 질문은 **예측된 HMM 상태 전환이 B3의 오차를 설명하며, 전환 방향에만 반응하는 작은 신경망 보정이 B3의 확률예측을 개선하는가**이다. 성능을 입증하기 전에는 `HMM+FiLM`이나 KAN 결합 자체를 신규 방법이라고 주장하지 않는다. HMM과 상태별 신경망의 결합 및 상태 기반 잔차 게이팅에는 선행연구가 있다([Energy Economics 2026](https://doi.org/10.1016/j.eneco.2026.109233), [2026년 프리프린트](https://arxiv.org/html/2608.12251v1)). 여기서 시험할 차이는 **직전 상태에서 다음 상태로 이동할 예측 확률을 방향별 조건 신호로 쓰고, 전환 가능성이 낮으면 B3에서 벗어나는 보정을 구조적으로 줄이는 것**이다. 최초성 주장은 별도 체계적 문헌조사 뒤에만 검토한다.

이 문서는 개발 전용 후속 연구를 설계한다. 기존 `results/`, `results_ar/`, B4 제출 선택, 2021-09-01~09-14 봉인 평가를 수정하거나 재사용해 후보를 고르지 않는다. A+ 프로토콜의 전날 관측, 달력, 당일 가동 계획 *대용값*만 사용한다. A+ 가동 플래그가 과거 실현 생산량에서 재구성됐다는 운영상 한계를 결과에 명시한다. 당일 목표 부하 `Y[d]`, 당일 실제 생산량, 사후 평활 상태는 발행 시점 특징이 아니다. B3의 `φ=0`, 3상태 조건부 전이, 백본, 기존 마스킹과 결측 처리 규칙을 기준으로 고정한다.

## 비교한 접근과 선택

1. **상태확률 FiLM**: 슬롯 `h`의 전이 후 예측 상태확률 `q_{h+1}`로 공유 신경망을 조절한다. 가장 단순한 조건부 기준선이지만 전환의 출발·도착 방향은 잃는다.
2. **전이흐름 FiLM + 전환 게이트**: 예측된 상태쌍 확률의 비대각 성분으로 공유 신경망을 조절하고 보정 크기에 전환확률을 곱한다. 이것을 단일 연구 후보로 선택한다. 상태별 신경망 3개보다 파라미터를 적게 쓰고, B3가 우세한 안정 구간에서 보정을 제한한다.
3. **KAN 전이 생성 또는 상태별 RNN**: 표현력은 크지만 현재 8개 겹친 개발 창과 약 242개의 일별 궤적에서 가설 분리·안정성·계산비용이 불리하다. 기존 B4-KAN은 시간대별 순환 스플라인을 전이 로짓에 넣은 변형이며 개발 MAE 11.382로 B4 기본형 10.956보다 높았다. 완전한 다층 KAN과 동일하지는 않지만, 이 단계의 우선 후보로 삼을 근거도 아니다.

## 발행 시점의 수학적 계약

날짜 `d`의 00:00에서 이전 날의 관측만으로 B3의 마지막 필터 상태 `q_0`을 얻는다. 당일 슬롯 `h=0…95`의 알려진 특징으로 `P_h = B3.trans(z_h)`를 계산한다. `q_h`를 **슬롯 h 전이 직전** 상태분포로 정의하면:

```text
J_h(i,j) = q_h(i) P_h(i,j)       # 상태쌍 예측 전이흐름, 3×3
q_{h+1}(j) = sum_i J_h(i,j)      # 슬롯 h의 전이 후 상태분포
s_h = sum_{i != j} J_h(i,j)     # 총 전환확률
```

`J_h`는 전이행렬이 아니다. 행합은 `q_h`, 열합은 `q_{h+1}`이며 모든 원소의 합은 1이다. 전이 방향 여섯 개 `vec_off(J_h)`만 FiLM 조건으로 쓴다. 동일한 `P_h`라도 전날 상태분포가 다르면 `J_h`가 달라진다. 현재 코드에서 `P_h`는 시간·가동·달력 특징의 함수이므로, 행렬만 원래 특징에 덧붙이는 것은 새로운 관측 정보를 추가하지 않는다. 발행 후의 당일 `Y`로 `q_h`를 갱신하지 않는다.

잔차 예측기는 공통 1-hidden-layer MLP(폭 16)를 사용한다. 입력 `x_h`는 A+에서 발행 시점에 알 수 있는 `z_h`와 B3 기준 예측 중심만 포함한다. FiLM은 `vec_off(J_h)`에서 생성한 `γ_h, β_h`로 숨은 특징을 `(1+γ_h)⊙hidden(x_h)+β_h`로 변조한다. 최종 보정은 다음과 같이 정의한다.

```text
M = 학습용 과거 OOF |Y - B3 중앙예측|의 90백분위수
Δ_h = M s_h tanh(head(FiLM(hidden(x_h), J_h)))
```

FiLM 생성기와 `head`의 마지막 선형층을 0으로 초기화하므로 시작 시 `Δ_h=0`이다. 또한 `|Δ_h| ≤ M s_h`여서 전환확률이 0이면 B3와 같다. 이 식은 **B3 대비 변화량의 상한**이지 MAE 비열등성 보장은 아니다. `M`은 각 외부 폴드의 학습용 OOF에서만 계산한다. `γ,β`를 만드는 수식과 보정 범위는 모델 선택 전에 고정한다. adaLN-Zero에서는 0초기화 원칙만 차용하며 Transformer/확산 모델 전체를 들여오지 않는다([FiLM 원 논문](https://ojs.aaai.org/index.php/AAAI/article/view/11671/11530), [adaLN-Zero 원 논문](https://openaccess.thecvf.com/content/ICCV2023/papers/Peebles_Scalable_Diffusion_Models_with_Transformers_ICCV_2023_paper.pdf)).

성능 대조군인 일반 잔차 MLP, `q`-FiLM, 게이트 없는 `J`-FiLM에는 동일한 `M tanh(head(…))`를 쓰고 마지막 연구 후보에만 `s_h`를 곱한다. 따라서 조건 신호와 전환 게이트의 기여를 분리해 비교한다.

예측 분포는 B3가 같은 날짜 seed로 생성한 2,000개 96슬롯 **공동 경로** 각각에 결정론적 `Δ_h`를 더해 얻는다. 슬롯 평균·중앙값·분위수·일최대·피크 시각·원시 초과확률을 모두 그 이동된 경로에서 다시 계산한다. 슬롯별 독립 분위수만 보정하고 일 피크를 따로 계산하지 않는다. B3의 기존 정확한 `φ=0` 피크 계산을 보정 후보에 그대로 재사용하지 않는다. 위험확률 보정은 학습 모델과 분리해 기존 strictly-past 규칙을 따른다. 원 B3와의 Brier 비교에는 공통 난수로 만든 경로 기반 B3 위험값도 함께 기록해 수치적 MC 차이를 분리한다.

## 단계별 실험과 중단 규칙

### 0단계: 발행 가능성과 전환 가설 진단

기존 `ar1…ar8`의 8개 pre-September 14일 rolling-origin 창과 seed 0/1/2에서 B3를 재현한다. 각 유효 슬롯의 절대오차, `q_h`, `P_h`, `J_h`, `s_h`와 마스크를 저장한다. 같은 창 안에서 `s_h` 상위 25% 슬롯과 나머지의 B3 MAE 차이를 보고한다. 동점 때문에 상위 집합이 구분되지 않으면 `uninformative`로 표시한다. 시간대·가동 여부별 오차도 병기해 단순한 시간대 교란 가능성을 드러낸다. 겹친 창을 독립 표본으로 보고 유의확률을 계산하지 않는다.

**진행 게이트:** `s_h`가 구분 가능하고, 상위 25%의 MAE가 나머지보다 큰 방향이 세 seed의 창평균 모두에서 같으며 각 seed의 8개 창 중 적어도 6개에서 같아야 1단계로 간다. 이 조건을 못 채우면 `transition_hypothesis_unsupported`로 종료한다. 이 진단은 인과효과 증거가 아니라 신경망 후보를 만들 가치가 있는지 보는 사전 스크리닝이다.

### 1단계: 최소 신경망 경로와 무누수 스모크

마지막 개발 창·seed 0·축소 epoch/경로 수로 `B3`, **HMM 정보 없는** 잔차 MLP, `q`-FiLM, `J`-FiLM, `J`-FiLM+`s` 게이트를 확인한다. 앞의 네 후보는 원인 분리용 대조군이며 마지막 하나만 연구 후보이다. 잔차 신경망의 폭·층·조건기 출력 차원은 같게 두고, 여섯 칸 조건 입력에는 순서대로 고정 0, 전이 후 `q`의 두 번 반복, `J`의 여섯 비대각 성분을 넣어 파라미터 수를 동일하게 유지한다. 모든 후보는 동일한 발행 가능 특징·기준 B3·학습행·튜닝행·MC 난수를 쓴다. `q` 및 `J`를 훈련 특징으로 만들 때에는 각 외부 폴드의 **학습 기간 안에서만** 시간순 내부 OOF B3 예측을 생성한다. FiLM 학습과 epoch 선택도 그 내부 OOF의 앞부분/마지막 부분으로 분리한다. 외부 검증일의 정답은 점수 계산 전까지 열지 않는다.

스모크는 `Δ=0`에서 B3 경로와 분위수가 동일한지, `J`의 행·열 주변합이 맞는지, 발행 당일 `Y`를 교란해도 `q/P/J/Δ`와 예측이 바뀌지 않는지, 전환확률 0인 합성 예에서 보정이 정확히 0인지 확인한다. 실패하면 전체 예산을 돌리지 않는다.

### 2단계: 전체 개발 비교

1단계가 통과하면 동일한 8개 창×3 seed에서 위 다섯 후보를 평가한다. 각 창에서는 학습용 내부 OOF로 보정기를 적합한 뒤 B3를 외부 학습 구간 전체에 재적합하고, 보정기와 B3를 고정한 채 외부 검증일을 발행한다. 주 지표는 슬롯 MAE, 부 지표는 CRPS다. 창별 값, seed별 평균·중앙값·최악값, 전환확률 상·하위 구간의 오차, `Δ` 크기, state/flow seed 안정성을 보고한다. 일 피크 MAE와 C50/C75/C90 Brier는 사건 수·보정 상태와 함께 보조 보고하며 희귀 사건 지표로 후보를 뒤집지 않는다. 음성 대조로 `J`를 같은 개발 창 안에서 날짜 단위로 교란한 조건을 **모델 선택 이후 진단으로만** 실행한다.

**채택 게이트:** 연구 후보가 B3보다 seed 0/1/2의 평균 MAE 모두 낮고, 세 seed 모두에서 평균 CRPS가 악화되지 않아야 한다. 또한 세 seed 모두에서 HMM 정보 없는 잔차 MLP, `q`-FiLM, 게이트 없는 `J`-FiLM보다 평균 MAE가 낮아야 HMM 정보·전환 방향·전환 게이트의 추가 기여를 주장할 수 있다. 교란된 `J`가 동일하게 개선하면 전환 방향의 기여 주장은 철회한다. 하나라도 실패하면 해당 성능·구성요소 기여를 주장하지 않고 B3를 남긴다. 반복 창의 개발 비교이므로 통과해도 확증적 우월성이라고 부르지 않는다.

### 3단계: 동결·외부 확인

2단계 통과 시 수식, 특징, 하이퍼파라미터, seed 규칙, 중단 규칙을 동결한다. 2021년 9월은 이미 본 기간이므로 재선택·재검증에 쓰지 않는다. 새 미공개 기간이 없다면 결론을 **pre-September 개발 결과**로 제한한다. 새 기간이 생기면 동결한 한 후보를 한 번만 평가한다.

## Luna 코드 설계 검토를 반영한 최소 변경면

- `gmst/hmm_core.py::CondHMM.trans`는 수정하지 않는다. 기존 `gmst/hmm_forecast.py::filter_last`, `day_tensors`, `forecast`에서 B3의 전날 필터 상태·당일 특징·공동 경로를 재사용한다.
- 새 `gmst/flow_film.py`: `issue_flow(state: HMMState, panel: Panel, d: int) -> FloatArray`는 `issue_centre`로 해당 발행일의 B3 기준값을 갱신한 뒤 `filter_last`·`day_tensors`를 호출해 `(96,3,3)`의 `J`를 반환한다. 동일 파일의 `FlowFiLM(nn.Module)`은 `(96,14+1)` 발행 가능 특징과 `(96,3,3)` 전이흐름에서 `(96,)` 보정을 반환한다. `shift_prediction(base: Prediction, delta: FloatArray, C: FloatArray) -> Prediction`은 공동 경로와 거기서 파생되는 모든 출력을 함께 갱신한다. 기능 하나를 위한 범용 추상화나 새 의존성은 만들지 않는다.
- 새 `gmst/flow_film_experiment.py`: 기존 `gmst/ar_experiment.py`의 rolling 창·seed·마스킹·출력 경로 거부 패턴을 재사용한다. `--diagnostic`, `--smoke`, 전체 실행을 분리하고 `results_flow/` 아래에 `diagnostic.csv`, `fold_metrics.csv`, `summary.csv`, `decision.json`을 저장한다. 공식 `results/` 및 `results_ar/`를 덮어쓰지 않는다. `run_development.py`, `run_all.py`, 기존 모델 선택 규칙은 수정하지 않는다.
- 새 `tests/test_flow_film.py`: (1) `J≥0`, 전체합 1, 행합 `q_h`, 열합 `q_{h+1}`, (2) 0초기화·`s=0`에서 B3 경로 동일, (3) 당일 목표 교란에 대한 발행 불변, (4) 보정 후 96슬롯·유한 경로·순서 있는 분위수·[0,1] 위험확률을 검증한다. 저장/CLI 스모크는 기존 테스트 관례에 맞춘 한 개의 통합 검사를 둔다.

이 인터페이스는 구현 계획의 출발점이며 실제 함수 시그니처는 기획서 승인 뒤 `superpowers:writing-plans`에서 호출부·타입과 함께 확정한다. 주어진 스펙만으로 2단계 전체 실험을 바로 실행하지 않는다.

## 알려진 한계와 보고 원칙

`J`는 `q`와 `P`로부터 계산한 구조화 표현이지 새 데이터가 아니다. 순환 스플라인 전이를 쓴 B4-KAN의 실패는 이 FiLM 후보의 실패를 증명하지 않지만 KAN 자체의 성능 근거도 아니다. B3 상태 의미와 점유율은 seed에 따라 흔들린 적이 있으므로 상태별 해석은 MAE/CRPS와 별도로 안정성을 통과해야 한다. 시간대·가동 정보가 전환확률과 오차 모두를 설명할 가능성은 HMM 없는 동일 용량 대조군과 시간대별 진단으로 점검한다. 봉인된 9월 수치와 기존 제출 규칙은 역사적 결과로만 인용한다.
