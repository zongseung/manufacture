# AR 축소 실험 설계

## 목적과 경계

기존 B3(φ=0)가 네 개발 폴드에서 B4보다 낮은 MAE·CRPS를 보인 이유를 분리한다. B4의 높은 초기 φ와 AR 계수의 무규제 적합을 각각 검증한다. 이미 완료된 2021년 9월 최종 평가는 학습·선택·재실행에 사용하지 않는다. `results/`와 기존 제출 모델 선택 규칙도 변경하지 않는다.

## 후보와 사전분포

동일한 백본, fold별 학습 구간, 튜닝·보정 분할, epoch·MC 예산으로 B1(비교 기준), B3(φ=0), 기존 B4, B4-low(φ 초기값 0.02, 무규제), B4-PC(같은 초기값, 상태별 AR(1) PC 사전분포)를 비교한다. PC 사전분포는 상수형 φ∈(0,1)에만 적용한다. 시변 IO 디코더와 KAN은 이 실험에서 제외한다.

φ=0을 기준으로 한 거리 `d(φ)=sqrt(-log(1-φ²))`와 `P(φ>u)=α`로 `λ=-log(α)/d(u)`를 정한다. 기본값은 사전 고정한 `u=0.5`, `α=0.05`다. 목적함수는 *관측 목표 슬롯당 평균* NLL이므로 상태별 PC prior의 음의 로그밀도 합을 관측 목표 슬롯 수로 나눈다. 밀도에는 변수변환 인자 `d'(φ)=φ/((1-φ²)d(φ))`가 포함된다. 이는 각 상태의 정상 Gaussian AR(1) 계수에 독립적으로 부여한 prior이며, switching HMM 전체에 대해 새로 유도한 PC prior라는 주장은 하지 않는다. B3만 정확한 φ=0 후보이다.

## 평가

2021-07-01부터 7일 간격의 7개 시작일과 2021-08-18 시작일, 총 8개의 14일 창을 사용한다. 창마다 시작 전 하루를 gap으로 두고 기존 event purge를 적용한다. 모든 검증 종료일은 2021-08-31 이하다. 겹치는 창을 독립 표본으로 간주하지 않는다. 각 창의 MAE·CRPS·보정 Brier와 유효 분모를 저장하고, 창별 MAE의 평균·중앙값·최악값을 seed 0/1/2별로 보고한다. 피크 Brier는 사건 수와 보정 상태를 함께 보고하며 후보 선택의 주 지표가 아니다.

B4-PC의 채택 기준은 세 seed 각각에서 평균 MAE가 기존 B4와 B4-low보다 낮고 B3보다 높지 않으며, seed별 MAE 우승 후보가 모두 B4-PC인 것이다. B4-low 대비 개선이 없으면 낮은 초기값만으로 설명 가능한 효과라서 PC prior를 채택하지 않는다. 동률은 B3를 우선한다. CRPS는 보조 지표로 공개한다. 기준을 충족하지 않으면 B3를 우선 후보로 남긴다. 겹치는 창의 유의확률이나 독립 CI를 산출하지 않는다. 이 판정은 연구 개발용이며 기존 9월 제출 결과를 바꾸지 않는다.

## 실행 표면

`uv run python -m gmst.ar_experiment --smoke --out <dir>`는 마지막 개발 창·seed 0·축소 예산으로 경로와 CSV를 검증한다. 기본 명령은 8개 창·3개 seed의 전체 예산을 별도 출력 폴더에 저장한다. 출력은 `fold_metrics.csv`, `summary.csv`, `decision.json`이며 기존 러너 산출물을 덮어쓰지 않는다. 잘못된 확률·출력 경로, 9월을 포함한 창은 실행 전에 거부한다.
