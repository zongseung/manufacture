# 일정 이동 절감액 검증 (A: 관측 유사일 반사실 검증 → C: 요금 규칙) — 2026-09-27

모델 구조는 바꾸지 않는다(C-BAT 기본값). 목적은 4장 절감액(예: −2,150원/일)처럼 모델이 계산하는 금액이
관측과 맞는지 평가하는 것이다.

## A. 사전 등록 (결과 확인 전 작성)

- 자연 실험: `results_v3/analog_days/pairs.csv`의 관측 유사일 쌍을 쓴다(같은 가동유형·날짜유형, 총생산 ±10%,
  시작 시각이 다르거나 첫 2시간 비중이 다른 쌍).
- 관측 차이: 같은 요금 달력(날 a의 날짜·공휴일)에 두 날의 실측 곡선을 대입한 전력량요금 차이
  ΔE_obs = E(Y_b) − E(Y_a), 그리고 요금 시간대(중간·최대부하) 피크 차이 ΔP_obs.
- 모델 차이: C-BAT 평균곡선에서 생산계획만 바꾼 반사실 차이. 날 a와 날 b를 각각 기준으로 계산해 평균한다.
  ΔE_mod = ½[(E(ŷ(a, q_b)) − E(ŷ(a, q_a))) + (E(ŷ(b, q_b)) − E(ŷ(b, q_a)))], ΔP_mod도 같은 방식.
- C-BAT은 2021-09-01 이전 전체 관측으로 한 번 적합한다(ConditionalConfig 기본값). 쌍의 날짜가 학습에 포함되므로 표본 내 검증이다.
- 판정(ΔE와 ΔP 각각): 원점 회귀 ΔX_obs = β·ΔX_mod의 β와 쌍 bootstrap 95% CI(2,000회).
  - "모델 금액 지지": CI가 1을 포함하고 0을 포함하지 않는다.
  - "방향만 지지": CI가 0을 포함하지 않지만 1을 포함하지 않는다(크기 보정 필요).
  - "지지 안 됨": CI가 0을 포함한다.
- 한 날이 여러 쌍에 들어가 쌍끼리 독립이 아니므로 CI는 실제보다 좁을 수 있다. 날짜 단위 cluster bootstrap도 함께 보고한다.

판정:
- **ΔE: 지지 안 됨.** 상관이 0이다. 평균 방향도 반대다. 관측에서는 시작이 늦은 날이 +7,359원 비쌌지만 모델은 −464원을 예측했다.
- **ΔP: 지지 안 됨**(날짜 cluster CI가 0 포함). 쌍 bootstrap으로는 방향만 지지된다. 모델의 피크 반응은 관측 차이의 약 1/10이다.
- 해석 주의: 관측 쌍은 생산계획 외에도 월·설비 상태 같은 다른 조건이 다를 수 있어 인과 기준값이 아니다. 따라서 "모델이 틀렸다"보다
  "모델 금액을 관측으로 뒷받침할 수 없다"가 정확한 결론이다.
